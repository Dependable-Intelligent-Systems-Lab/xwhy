# Tabular examples

Curated examples in preparation

`TabularExplainer` is implemented and available. This page tracks additional curated, reproducible examples with stored outputs that are still being prepared.

Planned example pages include binary classification, multiclass classification, regression, mixed numerical and categorical data, and explanation-stability comparisons.

Use the [Tabular explainer guide](https://dependable-intelligent-systems-lab.github.io/xwhy/explainers/tabular/index.md) and the generated API reference for the current executable interface.
