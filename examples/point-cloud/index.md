# Point-cloud examples

Curated examples in preparation

`PointCloudExplainer` is implemented and available. This page tracks additional curated, reproducible examples with stored outputs that are still being prepared.

- \[Point Cloud Explainer Examples\](https://dependable-intelligent-systems-lab.github.io/xwhy/examples/Point Cloud Examples/point_cloud_explainer_examples.ipynb): A Jupyter notebook demonstrating `PointCloudExplainer` on a standard PyTorch PointNet and a Hugging Face PointNet, along with stability analysis and 3D visualization.

Planned examples include object classification, point-group attribution, perturbation comparison, and interactive 3D visualisation.
