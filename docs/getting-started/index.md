# Get started with XWhy

Use this section to move from installation to a first interpretable result.

1. [Install XWhy](installation.md).
2. [Choose an explainer](choosing-an-explainer.md) that is currently implemented.
3. Follow the [quick-start workflow](quick-start.md).
4. Learn what is stored in an [explanation result](explanation-results.md).
5. Select a suitable [visualisation](visualisation.md).

!!! note
    The current supported starting points are image classification and LLM prompt-response explanation. Other public explainer classes are development interfaces and are not yet executable.
